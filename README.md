# CampusCore360

CampusCore360 is an Intelligent Campus ERP system designed to manage
campus operations through a centralized web application.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB

## 📁 Project Structure

CampusCore360/
├── Frontend/
├── Backend/
├── .gitignore
└── README.md

## ✨ Features

- User Authentication
- Campus Dashboard
- Student Management
- Faculty Management
- Academic Management
- Campus Administration
